Training-selected threshold 5.35%
How was the threshold selected?

The threshold was selected using only calibrated out-of-fold predictions from five-fold cross-validation in the NHANES training set. NHANES fasting subsample survey weights were used to maximize specificity while maintaining sensitivity ≥80%. The held-out test set was not used to select or adjust it.

The display is rounded to 5.35%; classification uses the full probability threshold of 0.0534945492990097. Survey weights were also used for model fitting, Platt calibration, and test performance estimates.
